# Ahorro Inteligente — Simulador y Comparador SFC v14

## Mejoras principales
- Selección sincronizada de entidades: lo elegido en **Comparar tasas** se usa automáticamente en **Simular ahorro** y **Riesgo y respaldo**.
- Nueva visualización moderna para la simulación:
  - barra horizontal apilada de capital + aportes + rendimiento;
  - gráfica de evolución mensual por entidad.
- Resumen institucional por banco seleccionado con:
  - origen;
  - antigüedad aproximada en Colombia;
  - grupo o respaldo corporativo;
  - enfoque principal;
  - breve reseña histórica;
  - enlace a fuente institucional.
- Se mantiene el análisis educativo de supervisión, seguro de depósitos, disponibilidad, solvencia, liquidez y calidad de cartera.
- Se conserva la lógica híbrida de tasas: comparador SFC, Datos Abiertos y respaldo local.

## Ejecución local
Ejecuta `Ejecutar_Ahorro_Inteligente.bat`.

La primera ejecución instalará las dependencias de `requirements.txt`, incluida `plotly`.
